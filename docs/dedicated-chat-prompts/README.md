# Dedicated Game Chat Prompts

Use these files to start separate working chats for each game. Each prompt keeps one game's mechanics, tone, open tasks, and route isolated so future design/build work does not get tangled across projects.

- `front-page-fortune.md` - historical headline allocation game at `#headline-market`
- `before-the-siege.md` - medieval future-omen survival game at `#before-siege`
- `options-fortune.md` - historical SPX options game, titled Expiration Date, at `#options-fortune`
- `futures-fortune.md` - grain futures headline game, titled Harvest Ledger, at `#futures-fortune`
- `sector-oracle.md` - sector-rotation investing game at `#sector-oracle`
